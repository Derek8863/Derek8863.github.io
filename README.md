# Derek 的博客

个人博客，使用 Jekyll 构建并由 GitHub Pages 托管。

访问：<https://derek8863.github.io/>

## 发布文章

在 `_posts/` 新建 `YYYY-MM-DD-title.md`，例如：

```markdown
---
layout: post
title: "文章标题"
description: "一句话简介"
date: 2026-09-24 10:00:00 +0800
---

正文从这里开始，支持 Markdown。
```

提交到 `main` 后，GitHub Pages 会自动构建并发布。博客标题和描述在 `_config.yml` 中修改。
